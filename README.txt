PUBLICACIÓN EN GITHUB PAGES
1. Descomprimir este ZIP.
2. Subir todos los archivos descomprimidos a la RAÍZ del mismo repositorio
   que publica el sitio de Chesterton. Reemplazar los antiguos.
3. Esperar que GitHub Pages publique la actualización y volver a abrir la app.
4. En algunos teléfonos, los íconos de una PWA ya instalada quedan
   guardados por Android/iOS. Si no cambia el ícono del acceso instalado,
   quitar únicamente esa instalación y volver a instalar desde el enlace
   existente. No es necesario borrar el repositorio ni la versión anterior.
