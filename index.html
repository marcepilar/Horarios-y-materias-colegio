Ayuda · Horario Escolar

Versión V1.3.7 · PWA para Android y iPhone

Esta aplicación muestra el horario semanal fijo, con materias y recreos de lunes a viernes. Se puede instalar en el teléfono y consultar sin abrir el navegador.

📚 Cómo usar la aplicación

  1. Tocá cualquiera de las cinco tarjetas horizontales para abrir las materias y los horarios de ese día.
  2. Deslizá hacia abajo si necesitás ver el resto de las clases y los recreos. Al elegir otro día, se cierra el anterior.
  3. El botón de arriba con tres puntos (•••) permite compartir por WhatsApp o mostrar un QR para escanear.
  4. El botón de tema alterna entre Dark Blue → Claro → Dark.

Las materias, los días y los horarios son fijos y no se modifican desde esta aplicación.

🤖 Instalar en Android

  1. Abrí la dirección publicada de Horario Escolar con Google Chrome, no desde el archivo HTML descargado.
  2. Tocá los tres puntos (⋮) de Chrome, en la esquina superior.
  3. Seleccioná Instalar aplicación. En algunos celulares aparece como Agregar a pantalla principal y luego Instalar.
  4. Confirmá Instalar. Encontrarás el ícono de Horario Escolar en el teléfono.

🍎 Instalar en iPhone

  1. Abrí el enlace publicado usando Safari.
  2. Tocá Compartir (cuadrado con flecha hacia arriba). En algunas versiones de iOS: Más → Compartir.
  3. Elegí Añadir a pantalla de inicio.
  4. Dejá activada la opción Abrir como app web, si aparece, y tocá Añadir.
  5. Abrí la aplicación desde su nuevo ícono en la pantalla de inicio.

🔄 Actualización y conexión

Para recibir una versión nueva, conectate a Internet y cerrá y volvé a abrir la aplicación. Las actualizaciones pueden requerir una segunda apertura. Si el ícono o el nombre no cambia, quizá tengas que reinstalarla.

Los horarios quedan disponibles sin conexión después de cargar correctamente la PWA. Para generar el QR con el enlace público necesitás conexión.

Seguridad: esta aplicación no necesita usuario ni contraseña. Nunca compartas contraseñas ni códigos de acceso para usarla.
