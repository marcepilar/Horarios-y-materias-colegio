Ayuda · Horario Escolar

Versión V1.4.1 · PWA para Android y iPhone

Esta aplicación muestra el horario semanal fijo, con materias y recreos de lunes a viernes. También incorpora un selector visual de año y división para futuras adaptaciones.

📚 Cómo usar la aplicación

  1. Tocá cualquiera de las cinco tarjetas horizontales para abrir las materias y los horarios de ese día.
  2. Deslizá hacia abajo si necesitás ver el resto de las clases y los recreos. Al elegir otro día, se cierra el anterior.
  3. El botón del curso (3A por defecto) despliega la lista para elegir entre 1 a 6 año y división A o B.
  4. El botón de compartir usa el ícono clásico de tres puntos unidos y permite compartir por WhatsApp o mostrar un QR.
  5. El botón de tema alterna entre Dark Blue → Claro → Dark.

Las materias, los días y los horarios publicados siguen siendo fijos y no se modifican desde esta aplicación.

🤖 Instalar en Android

  1. Abrí la dirección publicada con Google Chrome, no desde el archivo HTML descargado.
  2. Tocá los tres puntos (⋮) de Chrome en la esquina superior.
  3. Seleccioná Instalar aplicación. En algunos celulares aparece como Agregar a pantalla principal y luego Instalar.
  4. Confirmá Instalar. Encontrarás el ícono de Horario Escolar en el teléfono.

🍎 Instalar en iPhone

  1. Abrí el enlace publicado usando Safari.
  2. Tocá Compartir (cuadrado con flecha hacia arriba).
  3. Elegí Añadir a pantalla de inicio.
  4. Si aparece, dejá activada la opción Abrir como app web y luego tocá Añadir.

🔄 Actualización y conexión

Para recibir una versión nueva, conectate a Internet y cerrá y volvé a abrir la aplicación. Las actualizaciones pueden requerir una segunda apertura. Si el ícono o el nombre no cambia, quizá tengas que reinstalarla.

Los horarios quedan disponibles sin conexión después de cargar correctamente la PWA.

Seguridad: esta aplicación no necesita usuario ni contraseña. Nunca compartas contraseñas ni códigos de acceso para usarla.
